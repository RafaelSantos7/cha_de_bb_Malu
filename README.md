# Chá da Malu — Financeiro + Análises

## Recursos

- Gastos com valor previsto e valor final
- Entrada e pagamentos parciais
- Total pago e saldo calculados automaticamente
- Histórico de pagamentos
- Edição de gastos, convidados e fornecedores
- Gráfico de gastos por categoria
- Gráfico previsto × realizado
- Insights automáticos do orçamento
- Persistência local no navegador

## Executar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
